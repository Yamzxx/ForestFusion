# 🌲 ForestFusion

**Wildfire Risk Prediction and Forest Health Monitoring using Sentinel-2 Satellite Imagery, Weather Intelligence, and Machine Learning**

## Overview

ForestFusion predicts wildfire-prone regions by combining satellite observations with weather parameters such as temperature, humidity, wind speed, and rainfall.

The system calculates vegetation and moisture indices (NDVI, NDMI, and NBR), processes them using an XGBoost machine learning model, and visualizes wildfire risk through an interactive geospatial dashboard.

## Features

* Wildfire Risk Prediction
* Forest Health Monitoring
* NDVI, NDMI and NBR Analysis
* Interactive Wildfire Heatmaps
* Historical Wildfire Hotspots
* Weather-based Risk Analytics
* Alert Notifications
